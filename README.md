# Urban Auto — Tracking (кабінет клієнта)

Клієнт відкриває посилання `…/tracking/?c=КОД` і бачить: назву авто, VIN/лот, 6 етапів з датами та фото, букінг.
Дані автоматично беруться з повідомлень у вашій Telegram-групі.

```
Telegram-група ──► бот ──► Cloudflare Worker + D1 ──► сайт (index.html)
 (повідомлення,      (webhook)   (етапи, дати, фото)      кабінет клієнта
  фото)
```

## Що де лежить
| Шлях | Призначення |
|---|---|
| `index.html`, `css/`, `js/` | Сайт-кабінет (статичний, як і калькулятор — можна на GitHub Pages) |
| `js/config.js` | `API_URL` — адреса воркера. Поки порожній — показується демо (`?demo`) |
| `worker/` | Бот + API (Cloudflare Worker, база D1) |
| `worker/src/index.js` | Список етапів і ключові слова (`STAGES`) — підлаштовуються під ваші повідомлення |

## Як бот розуміє повідомлення
- **Яке авто:** VIN (17 символів) або `лот 12345678` у тексті/підписі. Першого разу картка авто створюється сама
  й бот відповідає посиланням для клієнта. Далі фото без VIN потрапляють до «поточного» авто чату;
  відповідь (reply) на повідомлення теж прив'язується до його авто.
- **Який етап:** якщо є рядок `Статус: …` (формат CargoPlus) — за ним, інакше за ключовими словами в тексті
  (див. `STAGES` у `worker/src/index.js`). Явно: `#3`, `#етап3`.
- **Дата етапу:** дата з тексту (`Розформування контейнера: 20.11.2026`), інакше час повідомлення. Майбутня дата —
  це план: на сайті «очікується 23 листопада», і етап ще не вважається пройденим.
- Фото (в т.ч. альбоми) потрапляють в етап повідомлення; альбоми без підпису — в етап останньої події авто.
- Назва авто береться з рядка `2015 FORD ESCAPE SE`.
- **Букінг:** рядок `Букінг: …` / `Booking: …` записується в картку й показується на сайті блоком під назвою авто.
- **Сповіщення:** після кожного оброблення бот відповідає в групі, що саме додано (авто, етап, дата, фото, букінг,
  посилання). Альбом без підпису дописується мовчки. Якщо в повідомленні є назва етапу, якої в трекері немає (напр. «Видача з терміналу»), бот його **пропускає**, нічого не зберігає й пише в групі, що такого етапу немає (фото-продовження цього альбому теж пропускаються).

Етапи: 1 Викуплено з Аукціону · 2 Отримання з аукціону · 3 Доставка · 4 Майданчик · 5 Завантаження в контейнер ·
6 Розформування контейнера (ключові слова — `STAGES` у `worker/src/index.js`).
- Клієнту **не** показується сирий текст групи — лише етап, дата й фото.

Команди в групі: `/car VIN Назва` · `/link` · `/stage N` · `/undo` · `/id` · `/help`

## Налаштування (один раз)
0. **Важливо:** бот не може читати *особистий* чат між вами й іншим ботом. Повідомлення CargoPlus мають потрапляти
   в групу, де є новий бот (або ви пересилаєте їх новому боту — пересланий текст і фото обробляються так само,
   дата береться з оригіналу, тож так можна «довантажити» історію).
1. **Бот:** у @BotFather — `/newbot`, потім для нього `/setprivacy` → Disable.
   Якщо повідомлення в групу пише *інший* ваш бот — у @BotFather увімкніть для нього **Bot-to-Bot Communication Mode**
   (інакше новий бот його повідомлень не побачить).
2. Додайте бота в групу (бажано адміном).
3. **Cloudflare (безкоштовно):**
   ```bash
   cd Tracking/worker
   npx wrangler login
   npx wrangler d1 create urban-auto-tracking      # database_id → у wrangler.toml
   npx wrangler d1 execute urban-auto-tracking --remote --file=schema.sql
   npx wrangler secret put BOT_TOKEN               # токен від BotFather
   npx wrangler secret put WEBHOOK_SECRET          # будь-який довгий випадковий рядок
   npx wrangler deploy
   ```
4. **Webhook:**
   ```bash
   curl "https://api.telegram.org/bot<BOT_TOKEN>/setWebhook" \
     -d "url=https://<ваш-воркер>.workers.dev/webhook" \
     -d "secret_token=<WEBHOOK_SECRET>" \
     -d 'allowed_updates=["message","channel_post"]'
   ```
5. У групі надішліть `/id` → впишіть число в `ALLOWED_CHATS` (`wrangler.toml`) і ще раз `npx wrangler deploy`.
   Також заповніть `SITE_URL` (адреса сайту трекера).
6. У `js/config.js` вкажіть `API_URL` воркера й опублікуйте папку `Tracking` (наприклад, у `urban-auto-calculator/tracking`).

## Обмеження
- Бот бачить лише повідомлення **після** додавання в групу; стару історію не підтягує.
- Зараз обробляються текст і фото (відео/документи ігноруються).
- Код клієнта в посиланні — «ключ» до кабінету: хто має посилання, той бачить авто.
